Diseña un prototipo web de alta fidelidad, moderno, profesional y funcional para un sistema hospitalario llamado SAMI – Sistema Administrativo Médico Integral, destinado al Hospital General Altotonga “Eufrosina Camacho”, ubicado en Altotonga, Veracruz, México.

El sistema debe tener una apariencia institucional, profesional y limpia, orientada a personal médico, enfermería, recepción, farmacia, administración, dirección y personal de Tecnologías de la Información. El diseño debe transmitir seguridad, confianza, organización y facilidad de uso, evitando una apariencia excesivamente comercial.

Identidad visual

Utiliza una interfaz web tipo dashboard administrativo hospitalario, con diseño responsive para computadora y tablet.

Utiliza:

Fondo general claro.
Tarjetas blancas con bordes sutiles y esquinas ligeramente redondeadas.
Tipografía moderna y altamente legible.
Color principal institucional en tonos azul oscuro/azul médico.
Color secundario en tonos turquesa o azul claro.
Verde para estados exitosos.
Amarillo para advertencias.
Rojo únicamente para errores o acciones críticas.
Iconografía médica y administrativa sencilla.
Alto contraste y buena accesibilidad visual.

En el encabezado debe aparecer:
SAMI
Sistema Administrativo Médico Integral

Incluir un área para el logotipo institucional del hospital.

Prototipado e interacción

Crear conexiones entre las pantallas para simular el funcionamiento real del sistema.

El flujo principal debe ser:

Inicio de sesión → Dashboard → Pacientes → Expediente clínico → Citas → Reportes

También permitir navegar desde el menú lateral hacia:

Personal, Usuarios, Roles y permisos, Farmacia e inventario, Auditoría, Respaldos y Configuración.

Los botones de “Ver”, “Editar”, “Nuevo”, “Guardar”, “Cancelar” y “Cerrar sesión” deben tener interacciones de prototipo.

Los modales deben abrirse mediante interacción.

Los formularios deben mostrar estados de validación.

Reglas de diseño

Mantener una experiencia de usuario profesional, intuitiva y accesible. Evitar saturar las pantallas con información innecesaria. Utilizar jerarquía visual clara, espaciado consistente, componentes reutilizables y navegación sencilla. Todas las pantallas deben pertenecer al mismo sistema visual y utilizar la misma identidad de SAMI.

El resultado debe parecer un software hospitalario real listo para ser presentado como prototipo académico, no una plantilla genérica de dashboard.

Utilizar únicamente datos ficticios de pacientes, médicos, usuarios y expedientes.

Crear el prototipo con suficiente detalle visual para que pueda utilizarse como evidencia del diseño y funcionamiento propuesto de SAMI – Sistema Administrativo Médico Integral.
